# 🚀 Explainify AI

**Explainify AI** is a simple yet powerful web app that turns complex topics into **easy, viral-style explanations**.

Ask anything — and get:

* ⚡ Simple explanations
* 🔥 Bold hook-style answers
* 📌 Clean bullet points
* 💡 Shareable content format

---

## 🌐 Features

* 🧠 AI-powered explanations (using Groq API + LLaMA 3)
* ✨ Viral content formatting (hook + simple + bullets)
* 💬 Chat-style UI (like ChatGPT)
* ⚡ Fast Flask backend
* 🎨 Modern UI with Tailwind CSS
* ⌨️ Typing animation + loader
* 📱 Fully responsive design
* 🎯 Example prompts for quick start

---

## 🛠️ Tech Stack

* **Backend:** Python + Flask
* **Frontend:** HTML + Tailwind CSS + JavaScript
* **AI Model:** LLaMA 3 (via Groq API)
* **API:** Groq Chat Completion API

## ⚙️ Setup & Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/explainify-ai.git
cd explainify-ai
```

### 2. Install Dependencies

```bash
pip install flask requests
```

### 3. Set Environment Variable

Set your Groq API key:

```bash
export GROQ_API_KEY=your_api_key_here
```

(Windows)

```bash
set GROQ_API_KEY=your_api_key_here
```

---

## ▶️ Run the App

```bash
python app.py
```

Open in browser:

```
http://127.0.0.1:5000
```

---

## 🧠 How It Works

1. User enters a question
2. Frontend sends request to `/explain`
3. Flask backend sends prompt to Groq API
4. AI generates structured response:

   * Bold Hook
   * Simple Explanation
   * Bullet Points
5. Response is displayed with typing animation
